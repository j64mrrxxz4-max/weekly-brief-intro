# AI 自动化周简报搭建指南

这是一个交互式幻灯片演示文稿，介绍如何使用 AI 自动化搭建周简报系统。

## 📂 文件说明

- **ai-presentation.html** - 主幻灯片文件（直接在浏览器中打开即可浏览）
- **netlify.toml** - Netlify 部署配置文件
- **图片文件** - 运维看板.jpg、项目进度看板.png 等截图

## 🚀 快速部署到 Netlify

### 方法 1：最简单（拖拽上传）

1. 访问 https://app.netlify.com/
2. 登录/注册账号
3. 将整个文件夹拖拽到上传区域
4. 完成！获得访问链接

### 方法 2：使用命令行（推荐）

```bash
# 1. 安装 Netlify CLI
npm install -g netlify-cli

# 2. 登录
netlify login

# 3. 部署
cd d:/Users/zhangf31/CodeBuddy/weekly-brief-intro
netlify deploy --prod
```

### 方法 3：Git 自动部署

1. 将代码推送到 GitHub/GitLab
2. 在 Netlify 连接仓库
3. 自动构建部署

详细部署说明请查看：**NETLIFY_DEPLOY.md**

## 💡 使用方式

- **键盘操作**：左右箭头键或空格键切换幻灯片
- **鼠标操作**：点击屏幕两侧的按钮切换
- **触摸操作**：左右滑动切换（移动设备）

4. 核心架构：从"数据孤岛"到"智能聚合"
